# Using resonance

Run `resonate` from the repository you want to inspect. On the first run, Resonance explains that the repository is not installed and asks whether to set it up. It then selects team packages, optionally registers packages from a personal member-workspace repository (leave the path blank to skip), and asks whether to start the server. You can also run `resonate install` directly; Shell is installed automatically, then you can select the optional team packages. Markdown files are discovered recursively, except inside `.git` and `node_modules`.

Select a document in the left navigation tree. Edit the source file in your editor, then reload the page to see the change.
