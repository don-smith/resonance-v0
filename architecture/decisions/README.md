# Architecture decision records

This directory contains the repository's architectural decision records (ADRs). Each ADR captures the context, decision, alternatives, consequences, and evidence for one bounded architectural choice.

Use the Architecture package's `write-adr` skill when creating or updating an ADR. Use the next zero-padded number in a filename such as `0001-hybrid-architecture-authority.md`.

`architecture/decisions.json` is the Architecture package's machine-readable index. Keep its decision entries linked to the corresponding ADR with `path` and `evidence` fields.
